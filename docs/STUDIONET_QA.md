# Real Studionet acceptance QA
Only the GitHub pull-request **opened** event triggers this workflow once.
It connects to the official hosted Studionet (chain ID 61999) using a fresh
random ephemeral account generated by the official `genlayer-test` package.
No user keys, GitHub secrets, payment transfers, mainnet, or Bradbury writes.

The test attempts a genuine deployment and 3 on-network contract write calls
(open issue, propose patch, AI consensus trace) plus state readbacks. It uses
no validator mocks; leader_only=false. A failing or unfunded account must fail
the workflow, not be reported as success. Canonical RPC preflight checks chain
identity before any transaction. If the RPC is inaccessible or the faucet needs
manual use, stop rather than inventing on-chain evidence.

Proof must include an on-chain address and a completed GitHub run. The
user's existing main branch and manual-only lint/Direct workflow are untouched.
